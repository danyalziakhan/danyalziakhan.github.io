## 3D pipeline and digital twin automation

Blender addons and Python tools for parametric and procedural generation of environment structures such as towers, bridges, and roads, built from blueprint measurements and technical documentation, with AI assisted inspection of the resulting geometry. Automated repair and preparation of generated or raw 3D models runs as part of the same pipeline. Built for studios that need production ready geometry without modeling every variant by hand.

## AI powered automation and agentic tools

Practical systems built on modern open weight models such as Qwen and Gemma, run locally. This covers image understanding, object detection and dimension estimation, Excel driven AI workflows, and agent style programs that combine reasoning, OCR, and visual analysis to replace slow manual processes.

## ComfyUI image generation and editing

Reusable ComfyUI workflows built on current open image models such as FLUX and Qwen Image, covering thumbnail generation, character generation, background removal, scene replacement, and style transfer. I can build from scratch or adapt an existing workflow to your requirements.

## Web scraping

Python based scrapers for anything from simple static pages to sites built to resist automation, handling authentication, anti bot measures, and proxy rotation. My Playwright framework supports parallel scraping, login automation, network interception, and infinite scroll for large scale data collection.

## Process automation

Python programs that take over repetitive work: large Excel and tabular data processing, grouping and aggregation, data cleanup, bulk file operations, scheduled tasks, and desktop or web workflows.

## Debugging and documentation

Fast, explained fixes for existing Python code, along with clear technical writing for tutorials and API documentation across Python, JavaScript, FastAPI, and React.
